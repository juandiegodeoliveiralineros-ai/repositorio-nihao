# Interactive Greeting Card Web App

Una aplicación web interactiva y responsiva diseñada como una tarjeta de felicitación personalizada, desarrollada con tecnologías web nativas sin dependencias externas.

## Demo en Vivo
[Ver proyecto en vivo](https://juandiegodeoliveiralineros-ai.github.io/repositorio-nihao/)

##  Tecnologías Utilizadas
* **HTML5:** Estructura semántica de la tarjeta y contenedores multimedia.
* **CSS3:** Estilos visuales, maquetación adaptable y animaciones.
* **JavaScript (Vanilla ES6+):** Manipulación dinámica del DOM y sistema de animación de partículas.

##  Características Principales
* **Interacción Dinámica:** Alternancia de estado en el botón de regalo e inserción programática de un contenedor de mensaje sorpresa.
* **Sistema de Partículas (Emojis Flotantes):** Generación en tiempo real de elementos animados con renderizado en coordenadas horizontales aleatorias.
* **Diseño Responsivo:** Tarjeta optimizada para correcta visualización en dispositivos móviles y de escritorio.
